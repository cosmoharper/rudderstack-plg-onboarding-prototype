Enable autoTrack Automatically capture pageviews, clicks, and form fills — no code required. View autoTrack docs →
OR instrument manually
▸ Instrument page call ⌃
rudder.page('Home');

Tracks every page view in your app.

▸ Instrument track call ⌃
rudder.track('Order Completed', { revenue: 99.00, product: 'Premium plan' });

Tracks user actions and key business events.

▸ Instrument identify call ⌃
rudder.identify('user_123', { email: 'user@example.com', name: 'Ada Lovelace' });

Ties events to known users and sets traits.

📋 Copy all (with SDK loader) ⌃

Paste this in your app's <head> — includes loader + autoTrack + all 3 calls.

<script> !function(){/* RudderStack loader */}(); rudder.load( 'WRITE_KEY_abc123', 'https://dataplane.rudderstack.com', { autoTrack: true } ); rudder.page(); rudder.identify('user_123', { email: 'user@example.com' }); rudder.track('Signed Up'); </script>
